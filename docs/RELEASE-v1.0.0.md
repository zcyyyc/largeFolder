# 大文件夹 v1.0.0 · Windows 便携版

首个公开版本：像手机大文件夹一样，用小卡片整理桌面上的文件、文件夹和快捷方式。

## 下载

下载附件 **LargeFolder-v1.0.0-windows-portable.zip**，解压到有写入权限的固定目录，双击 `LargeFolder.exe`。无需安装或管理员权限；需要 Windows 和 .NET Framework 4.x，已在 Windows 11 / .NET Framework 4.8 验证。

`Source code` 是源码，直接使用请下载上述便携 ZIP。`SHA256SUMS.txt` 可用于核对 ZIP 的 SHA-256。

## 主要功能

- 小卡片显示真实图标和文件名，单击直接打开；四宫格图标展开全部项目。
- 拖标题或空白处移动卡片，拖边缘或四角缩放，位置和两种视图尺寸自动保存。
- 展开后拖动图标排序，支持组内搜索、重命名、配色和多分组管理。
- 默认只添加入口；可主动收纳原件到程序目录，并保留还原记录和移动日志。
- 托盘管理、可选置顶与开机启动；程序无需联网。

## 数据与升级

首次运行自动生成 `data` 和 `storage`。备份或迁移时请一并保留；卸载前先还原已收纳原件。更新程序时只替换程序及说明文件，保留现有数据目录。

发布 ZIP 不包含任何个人配置、已收纳文件或本地测试数据。

## 验证与限制

源码在新目录下完成构建，39 项存储、36 项排序和 47 项几何/持久化检查通过，共 122 项。界面已验证移动、缩放、排序、小卡片打开和展开操作。

当前是独立桌面窗口，未嵌入 Explorer 桌面层；多屏和混合 DPI 的实机验证有限。EXE 暂未代码签名。
