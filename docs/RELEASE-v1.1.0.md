# 大文件夹 v1.1.0 · 自定义配色与桌面收纳

新增自定义调色盘和半透明卡片，并让拖入分组的桌面快捷方式真正从桌面移走。

## 下载

下载附件 **LargeFolder-v1.1.0-windows-portable.zip**，解压后双击 `LargeFolder.exe`。无需安装或管理员权限；需要 Windows 和 .NET Framework 4.x，已在 Windows 11 / .NET Framework 4.8 验证。

`Source code` 是源码；直接使用请下载上述便携 ZIP。`SHA256SUMS.txt` 可用于核对 ZIP 的 SHA-256。

## 本次更新

- 右键卡片 → 分组颜色 → 自定义颜色，打开系统调色盘，自由选色或输入 RGB。
- 半透明底色保留壁纸质感，图标和文件名保持清晰；深色卡片自动使用浅色文字。
- 桌面 `.lnk` / `.url` 快捷方式拖入后默认收纳，桌面图标随之移走，应用本身不移动。
- 按住 Ctrl 拖入或选择“仅添加入口”可保留桌面图标；普通文件和文件夹默认仍只添加入口。
- “整理桌面”默认移动所选项目；已有桌面快捷方式入口也可直接收纳，保留顺序与还原记录。

## 升级与数据

先退出旧版，再解压并替换程序及说明文件。**保留原有 `data` 和 `storage` 目录**，其中包含分组配置、还原记录和已收纳的真实文件。升级不会主动移动已有入口；已有分组可右键选择“收纳本组桌面快捷方式”，或使用“整理桌面”。

已收纳项目可通过右键菜单还原；原位置有同名项目时不会覆盖。发布 ZIP 不包含任何个人配置、已收纳文件或本地测试数据。

## 验证与限制

源码在独立目录重新构建，51 项存储、36 项排序及 47 项几何和持久化检查通过，共 134 项；包含真实跨卷收纳与还原。调色盘的取消、选色、深色文字适配和重启持久化已在隔离界面验证。

当前是独立桌面窗口，尚未嵌入 Explorer 桌面层；多屏和混合 DPI 的实机验证有限。EXE 暂未代码签名。
