大文件夹 1.1
像手机的大文件夹一样，给 Windows 桌面留出更多空间。

开始使用
1. 双击本目录的 LargeFolder.exe。无需安装，普通用户权限即可运行。
2. 桌面会出现一个小卡片。桌面上的快捷方式拖入后会收纳到分组，桌面图标随之移走；应用本身不移动。其他文件和文件夹拖入默认添加入口。
3. 小卡片按当前大小显示排在前面的项目图标和名称，单击项目即可直接打开；悬停可看完整名称和路径。
4. 单击分组标题、右上角“↗”或底部四宫格图标，进入大视图；大视图双击项目打开，Esc 收起。
5. 按住卡片顶部的名称区域或卡片空白处拖动，可移动整个卡片。右上角“···”打开分组菜单。

调整位置和大小
· 移动：按住标题或卡片空白处拖到桌面上的合适位置，松开即可；图标和按钮仍保留原来的点击功能。
· 缩放：把鼠标移到卡片边缘或四个角，光标变成调整大小的箭头后，按住拖动。拖动边缘可改宽或高，拖动角落可同时调整宽高。
· 松开鼠标后，位置和大小会自动保存，下次启动仍会沿用。拖动过程中按 Esc 可取消本次移动或缩放。
· 小卡片和展开的大视图分别记住各自的大小，调整其中一种不会覆盖另一种。
· 放大小卡片后，会显示更多可单击打开的快捷项目；显示顺序沿用你自定的排列。放不下的项目通过底部四宫格图标进入大视图访问。
· 想回到自动适配的尺寸，右键卡片或打开“···”菜单，选择“恢复默认大小”；这会同时恢复小卡片和大视图的默认大小，不改变项目顺序。

怎样真正减少桌面图标
桌面快捷方式（.lnk / .url）拖入或通过文件选择器添加时，默认移动到分组的收纳目录；按住 Ctrl 拖入，或选择“仅添加入口”，可保留原位置。其他文件和文件夹默认只添加入口。
右键卡片，或点击右上角“···”菜单中的“整理桌面（移入分组）”，勾选需要整理的项目；默认勾选移动到分组。已经添加为入口的桌面快捷方式，也可以直接选择“收纳本组桌面快捷方式”。
如果只想添加入口，取消“移动所选项目到分组”的勾选，再点“仅添加入口”。
如果想腾出桌面空间，保留“移动所选项目到分组”的勾选，再点“移入分组”。
所选原件将移动到 程序所在目录的 storage\分组编号，不是删除。
已收纳项目右键可“还原到原位置”。原位置存在同名项目时不会覆盖。
如果整理过程遇到权限、文件占用、取消等问题，请按提示核对原位置和收纳位置。
程序不收纳“此电脑”“回收站”等 Windows 系统图标。

日常操作
· 右上角“···”：新建分组、重命名、分组颜色、按名称排序、隐藏和删除分组。
· 自定义颜色：右键卡片 → 分组颜色 → 自定义颜色，打开调色盘或输入 RGB 数值。点“确定”应用并保存到当前分组，点“取消”保留原色。自定义深色会自动搭配浅色文字，卡片仍保留半透明效果。
· 右键项目：打开、定位、复制路径、移动到其他分组、前后调整顺序、移出分组。
· 自定排列：展开后按住图标拖动，绿色竖线指示插入位置，松开即可调整顺序并自动保存。重启后和收起预览都会沿用此顺序。
· 外层直接入口沿用排列顺序，数量随卡片宽高变化；项目超过当前可显示数量时会出现底部四宫格图标，点击展开后能访问全部项目。
· 拖动排序仅调整当前分组内的显示顺序；有搜索筛选时，按可见目标项的前后位置插入。
· 移出普通入口只移除入口，不删除原文件。
· 移出已收纳原件会先还原；含未还原原件的分组不能删除，以便保留还原记录。
· 若想保留收纳后的当前位置，可用“仅移出入口，保留当前位置”，原路径另存 data\移出记录.txt。
· 原文件被移动后，可右键“重新定位”重新选择文件或文件夹。
· 卡片采用浅色半透明底和深色文字，图标与文字保持清晰。默认按项目数量自动适配高度；手动缩放后沿用自定大小，不显示空格子。
· Ctrl+F 或菜单“搜索此分组”可显示搜索栏；只搜索当前分组项目名称，不搜索文件内容。
· 文件夹在小卡片单击、大视图双击后用资源管理器打开，不递归导入文件夹内的所有内容。
· 默认点击其他窗口会收起展开视图，可在分组菜单中关闭。
· 默认不置顶。需要浮在其他窗口上方时，可勾选“始终置顶”。
· 这是独立桌面窗口；Windows 的“显示桌面”等操作可能把它收起或隐藏。
  在系统托盘双击大文件夹图标，或再次运行 LargeFolder.exe，可显示全部分组。
· 托盘右键可新建分组、开机启动、打开目录和退出。退出后原件仍保存在原处或 storage 内。

快捷键
Esc        收起；拖动过程中取消本次移动或缩放
Ctrl+F     展开并搜索
Ctrl+O     添加文件或快捷方式
Ctrl+N     新建分组
F2         重命名当前分组
Enter      打开当前键盘焦点所在的项目

文件存放
LargeFolder.exe       主程序
LargeFolder.exe.config 运行配置
data\config.json      分组、入口、位置、两种视图的大小和设置
data\config.json.bak  上一次配置备份
data\error.log        出错时的本地记录
data\move-journal.jsonl 收纳和还原前写入的路径日志，意外中断时可据此手动核对恢复
storage\              用户主动收纳的原件
src\                  完整 C# 源码、图标和 manifest
build.ps1             本机 .NET Framework 编译脚本
tests\                独立测试及测试报告（不操作真实桌面）

备份与卸载
建议备份整个程序目录，尤其是 data 和 storage。
请勿直接删除 storage，它可能含有你收纳的真实文件。
不再使用时：先还原已收纳原件，关闭开机启动，再从托盘退出。
本软件不联网，不上传文件，不自动收纳桌面，也不自动创建开机启动项。
收纳日志不会自动重放。如发生中断，请核对日志中的 source 与 destination，不要直接删除任一目录。

重新编译
关闭程序后，在 PowerShell 执行：
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
编译使用 Windows 自带 .NET Framework，无需下载 NuGet 包或 .NET SDK。
